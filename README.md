# Paradise Nursery – Online Plant Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application developed using React. It provides a simple and interactive platform for customers to explore and purchase different varieties of indoor houseplants.

Users can browse plants organized into categories, view their names and prices, and add their favorite plants to a shopping cart. The application also allows users to manage cart quantities, remove products, and calculate the total purchase amount.

## Features

- Attractive landing page with a background image.
- Company introduction and information.
- Product listing with multiple houseplant categories.
- Plant images, names, and prices.
- Add to Cart functionality.
- Dynamic shopping cart item counter.
- Increase and decrease product quantities.
- Remove products from the shopping cart.
- Automatic calculation of cart totals.
- Navigation between Home, Plants, and Cart pages.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Redux
- React Router DOM
- Vite

## Installation and Setup

1. Clone this repository.
2. Open the project directory.
3. Install dependencies using `npm install`.
4. Start the development server using `npm run dev`.
5. Open the local URL displayed in the terminal.

## Deployment

The application will be deployed using GitHub Pages.
